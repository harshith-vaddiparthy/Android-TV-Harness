# Terms

- Target: one native ADB serial or host:port belonging to the owner's TV.
- Plan: a persisted, expiring description of exact actions and prior state.
- Run: checkpointed attempted/verified actions and their result.
- Restore: recover touched package enabled settings and original Home; remove only the launcher newly installed by that run.
- Workspace: an existing agent app or browser destination to be connected later.
- Launcher: `com.gathin.tvhome`, a native Android Home activity.
